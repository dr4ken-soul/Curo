# curo — Recording Guide

## The style

Plain visual screen recording. Nothing else.

- No voiceover
- No spoken words of any kind
- No captions, no subtitles, no text overlays, no title cards
- No music, no sound effects
- The app itself is the narrator

Every label, number and status on screen was designed to carry the story without a single spoken word. Read through the console once before recording so the sequence makes sense as a silent film.

## Before recording

1. Check the submission form for the required video length and format. Record to match it.
2. Close every other window. Browser fullscreen, F11.
3. Set the screen to 1920x1080 if available, at minimum 1280x800.
4. Warm the app up first, load the console, let the cache fill, so the recording starts on a fully rendered screen.
5. Do one full practice run. Watch it. Fix anything that was unclear in the practice run before the real take.

## The take

1. Start the recorder, open the app. The console blurs in, the map draws the heat grid, the counters count up. Hold three to five seconds.
2. Move the cursor slowly and deliberately. Every cursor movement should have a purpose. Never wiggle it.
3. Click a grid cell to select the site. The callout pins, the rail computes. Pause so the status module is readable.
4. Move to the hour strip, pause on the current hour and the hottest forecast hour.
5. Show the calendar. Pause on a green day, then an amber day, then the labels that say forecast and climatology.
6. Trigger the breach alert on the real hottest hour. Let it sit on screen for a full four seconds. The headline reads by itself.
7. Dismiss the alert, open the export drawer, show the csv preview, download one file.
8. End on the counters with the assumption labels visible. Hold five seconds.
9. Stop the recorder.

## Editing rules

Cheap cuts for dead air are fine. Nothing else. No captions, no zooms, no effects, no audio track. If a section runs long, cut it, do not caption it.

## The checklist

- [ ] Video length matches the submission form requirement
- [ ] 1080p, fullscreen, no other windows visible
- [ ] One live api fetch visibly on screen, so the data is provably real
- [ ] The breach alert fired on real data, with the margin number visible
- [ ] The counters and their assumption labels visible in the final frame
- [ ] No narration, no captions, no music, complete silence
- [ ] Watched the full take once before uploading
